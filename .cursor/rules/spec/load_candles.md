# LoadCandlesTgFeature - Спецификация

## Описание

Telegram фича для выгрузки месячных свечей акций Московской биржи за последние 36 месяцев с использованием Tinkoff Investments API. Формирует Excel файл с данными и отправляет статистику по свечам.

## Команда

- Команда: `t_invest_candles`
- Описание: "Выгрузить свечи"

## Функциональность

### Входные данные

- Тикер акции (например: `NLMK`) - передается в тексте сообщения
- Только акции Московской биржи (MOEX)

### Процесс работы

1. **Проверка прав доступа**
   - Проверяется, что пользователь является админом через `CheckTgAdmin`

2. **Получение тикера**
   - Тикер извлекается из `msg.text`
   - Приводится к верхнему регистру
   - Если тикер не указан, отправляется сообщение с просьбой указать тикер

3. **Получение свечей**
   - По тикеру получается `figi` через Tinkoff Investments API
   - Используется `share_by` с `class_code="TQBR"` для акций MOEX
   - Fallback: `find_instrument` если `share_by` не сработал
   - Получаются месячные свечи за 36 месяцев по `figi`
   - Интервал: `CANDLE_INTERVAL_MONTH`

4. **Формирование Excel файла**
   - Создается файл с двумя колонками:
     - **Месяц Год** - формат `MM.YYYY` (например: `01.2025`)
     - **Изменение (%)** - процентное изменение цены за месяц
   - Данные сортируются по убыванию даты (от новых к старым)
   - Цветовое форматирование:
     - Зеленый (`#90EE90`) для положительных изменений (рост)
     - Красный (`#FF6B6B`) для отрицательных изменений (падение)
   - Заголовки выделены серым фоном и жирным шрифтом
   - Ширина колонок: A=15, B=18

5. **Расчет статистики**
   - Минимальное падение (в процентах)
   - Максимальное падение (в процентах)
   - Среднее падение (в процентах)
   - Минимальный рост (в процентах)
   - Максимальный рост (в процентах)
   - Средний рост (в процентах)
   - Вероятность роста: процент месяцев с ростом от общего количества

6. **Отправка результатов**
   - Excel файл отправляется через `BotMsgRepo.send_document`
   - Имя файла: `{ticker}_candles_36m.xlsx`
   - Статистика отправляется текстовым сообщением через `BotMsgRepo.send_text`

## Формат статистики

```
📊 Статистика по {ticker}:

🔴 Падения:
  Мин падение: -X.XX%
  Макс падение: -X.XX%
  Среднее падение: -X.XX%

🟢 Рост:
  Мин рост: X.XX%
  Макс рост: X.XX%
  Средний рост: X.XX%

📈 Вероятность роста: XX% (X мес роста из X)
```

## Архитектура

### Зависимости

- `BotMsgRepo` - для отправки сообщений и файлов
- `CheckTgAdmin` - для проверки прав доступа
- `TinkoffCandlesRepo` - для получения свечей через Tinkoff API

### Репозитории

#### Порт: `TinkoffCandlesRepo`
- Расположение: `kys_in_rest/money/features/repos/tinkoff_candles_repo.py`
- Метод: `get_monthly_candles(ticker: str, months: int = 36) -> list[Candle]`

#### Инфраструктура: `TinkoffInvestCandlesRepo`
- Расположение: `kys_in_rest/money/infra/tinkoff_candles_repo.py`
- Реализация через `tinkoff.invest.Client`

### Сущности

#### `Candle`
```python
@dataclass
class Candle:
    open: float      # Цена открытия
    close: float     # Цена закрытия
    high: float      # Максимальная цена
    low: float       # Минимальная цена
    time: datetime   # Время свечи
    volume: int      # Объем
```

## IoC регистрация

В `kys_in_rest/applications/ioc.py`:

```python
# Токен передается через параметр tinkoff_invest_token
ioc.register(
    TinkoffCandlesRepo,
    lambda: TinkoffInvestCandlesRepo(tinkoff_invest_token),
)
```

## Переменные окружения

- `TINKOFF_INVEST_TOKEN` - токен для доступа к Tinkoff Investments API

## Обработка ошибок

- Если тикер не указан - отправляется сообщение с просьбой указать тикер
- Если инструмент не найден - `ValueError` с сообщением "Инструмент {ticker} не найден на Московской бирже"
- Если не удалось получить свечи - отправляется сообщение об ошибке
- Все исключения перехватываются и отправляются пользователю

## Особенности реализации

1. **Получение figi по тикеру**
   - Основной метод: `client.instruments.share_by()` с `class_code="TQBR"`
   - Fallback: `client.instruments.find_instrument()` с поиском по бирже MOEX

2. **Сортировка данных**
   - В репозитории: от старых к новым (для расчетов)
   - В Excel: от новых к старым (для удобства просмотра)

3. **Расчет процента изменения**
   - Формула: `((close - open) / open) * 100`
   - Округление до 2 знаков после запятой

4. **Расчет вероятности роста**
   - Формула: `(growth_count / total) * 100`
   - Округление до целого числа
